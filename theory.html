Aim

To predict the risk of heart attack from patient data using a Random Forest classifier, evaluate it with accuracy, confusion matrix and classification report, and interpret the important risk factors using SHAP.

Algorithm

  1. Load the heart attack prediction dataset.
  2. Encode Sex and Diet, split Blood Pressure into systolic and diastolic values and drop unnecessary columns.
  3. Separate features and target, standardise the features and split into 70% training and 30% testing data.
  4. Train a Random Forest classifier (100 trees, balanced class weights).
  5. Predict on the test data and compute accuracy, confusion matrix and classification report.
  6. Explain the model with SHAP, plot the summary plot and re-plot it with the class-1 SHAP values.

Conclusion

A Random Forest model was built to predict heart-attack risk from patient data and was explained using SHAP. The model reached 63.9% accuracy but detected almost none of the high-risk patients, showing that accuracy is not enough for imbalanced medical data and that recall, resampling and threshold tuning are needed in disease risk prediction.
