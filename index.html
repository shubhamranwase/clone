Aim

To install Apache Sqoop 1.4.7 on Ubuntu, connect it with the existing Hadoop installation, install the required Java libraries and MySQL JDBC driver, configure a dedicated MySQL user, and verify that Sqoop is ready to communicate with the relational database server.

Short Theory

Apache Sqoop (derived from "SQL-to-Hadoop") is a command-line utility designed to transfer structured data efficiently between relational databases (like MySQL) and the Hadoop ecosystem. Since relational databases store data in tables and Hadoop stores data in distributed HDFS files, Sqoop acts as the transfer bridge using a JDBC driver to connect both environments.

Steps and Code

Part A: Installation and Configuration

  1. Extract Sqoop: Extract the downloaded Sqoop archive and move it to a permanent directory. 
    sudo mv sqoop-1.4.7.bin_hadoop-2.6.0 /usr/local/sqoop
  2. Set Environment Variables: Add Sqoop to the Linux environment by editing ~/.bashrc: 
    export SQOOP_HOME=/usr/local/sqoop
export PATH=$PATH:$HADOOP_HOME/bin:$SQOOP_HOME/bin
  3. Link Hadoop to Sqoop: Copy sqoop-env-template.sh to sqoop-env.sh and set HADOOP_COMMON_HOME and HADOOP_MAPRED_HOME to /usr/local/hadoop.
  4. Add Database Driver: Copy the MySQL JDBC driver (mysql-connector-java-5.1.49.jar) into the /usr/local/sqoop/lib/ directory so Sqoop can communicate with MySQL.

Part B: Database Preparation (MySQL)

  1. Open MySQL: Execute sudo mysql in the terminal.
  2. Create Sqoop User: 
    CREATE USER 'sqoopuser'@'localhost' IDENTIFIED WITH mysql_native_password BY 'Sqoop123';
  3. Create Database and Table: 
    CREATE DATABASE sqoop_demo;
USE sqoop_demo;
CREATE TABLE employee (emp_id INT PRIMARY KEY, emp_name VARCHAR(50), department VARCHAR(30), salary INT);
  4. Insert Records: 
    INSERT INTO employee VALUES 
(1,'Aarav','CSE',45000), 
(2,'Diya','IT',55000), 
(3,'Kabir','AI',62000), 
(4,'Meera','CSE',48000), 
(5,'Rohan','Data Science',70000);
  5. Grant Permissions: 
    GRANT ALL PRIVILEGES ON sqoop_demo.* TO 'sqoopuser'@'localhost'; 
FLUSH PRIVILEGES;

Part C: Sqoop Execution (Data Transfer)

  1. Test Connectivity: 
    sqoop list-databases --connect "jdbc:mysql://localhost:3306/?useSSL=false" --username sqoopuser -P
  2. Full Table Import into HDFS: 
    sqoop import \
--connect "jdbc:mysql://localhost:3306/sqoop_demo?useSSL=false" \
--username sqoopuser -P \
--table employee \
--target-dir /sqoop/employee_data \
--num-mappers 1
  3. Filtered Table Import: 
    sqoop import \
--connect "jdbc:mysql://localhost:3306/sqoop_demo?useSSL=false" \
--username sqoopuser -P \
--table employee \
--where "salary > 50000" \
--target-dir /sqoop/high_salary \
--num-mappers 1

Output Verification

1. Verification of Full Import in HDFS:

hdfs dfs -cat /sqoop/employee_data/part-m-00000
1,Aarav,CSE,45000
2,Diya,IT,55000
3,Kabir,AI,62000
4,Meera,CSE,48000
5,Rohan,Data Science,70000

2. Verification of Filtered Import in HDFS:

hdfs dfs -cat /sqoop/high_salary/part-m-00000
2,Diya,IT,55000
3,Kabir,AI,62000
5,Rohan,Data Science,70000

Conclusion

Apache Sqoop 1.4.7 was successfully configured on Ubuntu with the necessary Hadoop paths and MySQL JDBC drivers. A dedicated sqoop_demo database and employee table were created in MySQL, and records were seamlessly transferred to HDFS using sqoop import. The practical concluded by successfully verifying both full and filtered (salary > 50000) data imports using standard HDFS commands.
